# Smart Clinic Assistant

Smart Clinic Assistant is a graduation project that aims to build an intelligent clinic support system.

## Main Features
- AI chat assistant for patients
- Appointment booking and management
- Skin image analysis support
- Doctor/admin dashboard
- Retrieval-Augmented Generation (RAG) for medical and patient information
- Local demo environment using fake data only

## Project Structure

- `backend/` → API and database layer
- `frontend/` → web interface
- `llm_agent/` → LLM agent and tool calling
- `rag/` → retrieval system and vector database
- `cv_model/` → skin image classification model
- `docs/` → project documentation and planning
- `scripts/` → helper scripts

## Current Status
Initial repository structure has been created.

## Notes
